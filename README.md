# Sophisticated Storage Fixes

A small add-on for Sophisticated Storage that fixes flickering or incorrect item displays on barrels, especially when your storage area crosses a chunk boundary.

It keeps the items shown on the front of each barrel consistent as you move around your storage area. Your stored items and the way you use your barrels stay the same.

Simply add the mod to your Minecraft mods folder and restart the game. No configuration is needed. Install it on your client; servers do not need it.

## Requirements

- Minecraft 1.20.1 with Fabric Loader 0.16.9 or newer
- Sophisticated Storage (Fabric) 1.20.1-1.3.5.11.142
- Sophisticated Core 1.20.1-1.2.7.15.166

This version requires the exact Sophisticated Storage and Sophisticated Core versions listed above.
